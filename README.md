# AI 文案健檢｜5力商業文案評分 Skill

一個以廣告代理商提案標準設計的繁體中文 Codex Skill，從五個面向診斷商業文案，給出一致、可比較的分數與可立即執行的修改方向。

它不問「這篇文章寫得順不順」，而是問：

> 這份文案，能否在競爭激烈的商業環境中替客戶贏得生意？

## 評估什麼

| 面向 | 核心問題 |
| --- | --- |
| 商業力 | 策略、價值主張、信任與 CTA 能否推動商業結果？ |
| 推導力 | 結構、邏輯與資訊設計能否完成說服？ |
| 感受力 | 文案是否真正理解受眾，建立情感與品牌溫度？ |
| 創新力 | 概念、角度與記憶錨點是否具辨識度？ |
| 字詞力 | 用字、句法、節奏與語氣是否精準、有力、有質感？ |

每個面向採 1–10 分評估，並以代理商專業標準校準：

- **9–10｜頂尖**：具鮮明競爭優勢；10 分保留給極罕見的成熟作品。
- **7–8｜專業**：符合代理商內部審核標準，只需聚焦優化。
- **5–6｜合格**：核心概念成立，但仍需要資深人員修改。
- **1–4｜待加強**：存在明顯策略或執行缺陷。

## 它會產出什麼

```text
5力文案健檢報告
商業力：7 / 10
推導力：6 / 10
感受力：8 / 10
創新力：6 / 10
字詞力：7 / 10

【總監短評】
[最強優點、最大弱項，以及一項具體優化建議]
```

在同一輪完成五篇分析後，Skill 會整理各面向平均分數，並診斷寫作者較接近作家型、業務型、學術型、老鳥型、小白型或混合型。

## 適用情境

- 廣告、社群貼文、銷售頁與品牌內容審稿
- 提案前的文案品質檢查
- 比較多個標題、版本或創意方向
- 找出寫作者長期穩定的強項與盲點
- 將「感覺不對」轉化為可討論、可修改的專業判準

## 使用方式

將此 repository 下載或 clone 到 Codex 的 skills 目錄：

```bash
git clone https://github.com/cityminutes/ai-copywriting-audit-zh.git ~/.codex/skills/ai-copywriting-audit-zh
```

接著在 Codex 中輸入：

```text
使用 $ai-copywriting-audit-zh 評估以下文案。

目標受眾：第一次創業的小型品牌主
媒介：Instagram 廣告
商業目標：預約免費諮詢

[貼上文案]
```

提供目標受眾、媒介與商業目標，能讓評分更貼近真實情境；若資訊不足，Skill 會先說明採用的假設，不會捏造產品證據。

## 設計原則

- 依文案格式調整指標權重，不拿完整銷售頁標準苛求一句標題。
- 不因篇幅長、資訊多或文字華麗而自動給高分。
- 以文案中的可觀察證據校準分數。
- 提供精煉結論與可執行建議，不輸出冗長的隱性推理。
